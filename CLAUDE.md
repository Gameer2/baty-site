# Working style

Match process weight to task size.

- For simple, well-defined tasks (a small edit, a one-file fix, a clear ask) — just do the work directly. Do not invoke brainstorming, planning, or other heavy process skills first. Do not write out a multi-step plan for something that doesn't need one.
- Reserve brainstorming/planning skills for genuinely large, ambiguous, or multi-file feature work where the approach actually needs to be decided first.
- This instruction overrides any skill (including superpowers) that would otherwise force planning/brainstorming before every task.
