Partial Differential Equations

Laplace's and Poisson's Equations

Laplace's equation u_xx + u_yy = 0 on a rectangle with Dirichlet data on up to four edges, solved two independent ways — the sinh-series from separation of variables and numeric relaxation (Jacobi/Gauss-Seidel on the 5-point stencil) — and shown only once they agree. Poisson's equation u_xx + u_yy = f(x,y) with zero Dirichlet data is solved by relaxation and verified by substituting back into the discrete equation.

Input

uxx + uyy = 0 on 0 < x < a, 0 < y < b, with Dirichlet data on each edge. Leave an edge as 0 for a fixed (zero) side.

Ready — press Solve.
Output

Set the rectangle and the Dirichlet data on each edge, then solve — the sinh-series (cross-checked against relaxation) and the solution heatmap will appear here.

u(x,y) — solution over the rectangle
Input

uxx + uyy = f(x,y) on 0 < x < a, 0 < y < b, with zero Dirichlet data (all four edges fixed at 0).

The default is the forcing whose exact solution is sin(πx)sin(πy) — a single symmetric bump.
Ready — press Solve.
Output

Set the rectangle and the source f(x,y), then solve — the relaxation solution (verified against the discrete equation) and the heatmap will appear here.

u(x,y) — solution over the rectangle
