Partial Differential Equations

Heat Equation

The diffusion equation u_t = k·u_xx on 0 < x < L, with the ends held at zero (u(0,t) = u(L,t) = 0, Dirichlet) and an initial temperature profile u(x,0) = f(x). Separation of variables turns the PDE into an eigenvalue problem in x (whose sine modes satisfy the boundary conditions) and a decay ODE in t; the initial profile is then matched by its Fourier sine coefficients, computed here by Simpson's rule. The temperature surface u(x,t) relaxes toward the steady state.

Input

ut = k·uxx on 0 < x < L, with u(0,t) = u(L,t) = 0 (Dirichlet) and u(x,0) = f(x).
