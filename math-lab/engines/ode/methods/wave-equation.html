Wave Equation

The wave equation u_tt = c²·u_xx on 0 < x < L, ends fixed (u(0,t) = u(L,t) = 0), initial position u(x,0) = f(x) and initial velocity u_t(x,0) = g(x). Solved two independent ways — the standing-wave (normal-mode) series from separation of variables, and d'Alembert's traveling-wave form — and shown only once they agree numerically.

Input

utt = c²·uxx on 0 < x < L, with u(0,t) = u(L,t) = 0 (Dirichlet), u(x,0) = f(x), ut(x,0) = g(x).
