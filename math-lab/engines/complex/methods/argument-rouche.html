Argument Principle & Rouché's Theorem

Two theorems that count zeros and poles from a single loop. The argument principle: (1/2πi) ∮γ f′(z)/f(z) dz = N − P, the number of zeros minus poles inside γ — equivalently the winding number of f(γ) about the origin. Rouché's theorem: if |f − g| < |f| everywhere on γ, then f and g have the same number of zeros inside. Both are computed two independent ways — the argument principle is checked by agreeing the winding number (geometric angle-tracking) against the logarithmic-derivative integral (analytic quadrature); Rouché by confirming the two winding numbers actually agree once the condition holds. The image curve f(γ) is drawn in the w-plane so you can see the winding directly.
