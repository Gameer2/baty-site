Newton's Method for Nonlinear Systems

Generalizes Newton-Raphson to n equations in n unknowns — each step solves the linear system J(x_{k-1}) δ = -F(x_{k-1}) using a numerically approximated Jacobian, then x_k = x_{k-1} + δ.
