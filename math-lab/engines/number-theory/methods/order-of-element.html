Order of an Element

The multiplicative order of a mod n is the smallest k > 0 with a^k ≡ 1 (mod n). Lagrange's theorem for the integers: the order always *divides* φ(n), so the search need only test divisors of φ — never all of them. An element whose order equals φ(n) is a primitive root (next page).

Input
Try 2 mod 7: order 3 (divides φ(7)=6). Try 2 mod 4: gcd≠1, order undefined.
