Modular Exponentiation

The single operation that all of public-key cryptography rests on: compute base^exp mod m without ever holding the astronomically large base^exp. Binary (square-and-multiply) exponentiation reads the exponent bit by bit — square the base every step, multiply into the accumulator only when the bit is 1 — so the cost grows with the *number of bits* of the exponent, not its size. This is the page RSA, Diffie–Hellman, and every primality test below are built on.

Input
3^13 mod 7 = 3, done in 4 squarings — 3^13 itself is 1,594,323, never formed. The bit table below shows exactly which steps multiply.
