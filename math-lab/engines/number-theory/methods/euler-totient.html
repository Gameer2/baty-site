Euler's Totient φ(n)

φ(n) counts the integers up to n that are coprime to n — the size of the multiplicative group mod n, and the exponent in Euler's theorem. For a prime power p^k, φ = p^k − p^(k−1); and φ is multiplicative, so for n = ∏ pᵢ^eᵢ the product formula folds it all together: φ(n) = n · ∏(1 − 1/pᵢ).

Input
Any integer ≥ 1. The factorisation drives the product formula; φ is built from the distinct primes, not by counting.
Output

Enter n — the factorisation, the product-formula breakdown, and φ(n) will appear here.
