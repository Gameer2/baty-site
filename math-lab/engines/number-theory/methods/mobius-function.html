Multiplicative functions

Möbius Function & Inversion

μ(n) is +1 if n is square-free with an even number of prime factors, −1 if square-free with an odd number, and 0 the moment any prime repeats. Alongside it sit the counting functions that often get confused: ω(n) (distinct primes), Ω(n) (primes with multiplicity), and Liouville's λ(n) = (−1)^Ω. The difference between "with" and "without multiplicity" is exactly where students slip on τ and σ — here they're laid out side by side.

Input
Any integer ≥ 1. All four functions reuse the same factorisation. Try 12 (= 2²·3, not square-free → μ = 0) versus 30 (= 2·3·5, square-free, 3 primes → μ = −1).
Output

Enter n — μ(n), ω(n), Ω(n), λ(n), the factorisation, and the square-free verdict will appear here.
