Linear Congruences

Solve ax ≡ b (mod n). Unlike an ordinary equation, one congruence can have *many* solutions — exactly gcd(a, n) of them, and only when that gcd divides b. The reduced solution class lives mod n / gcd(a,n); the full set fans out from there.

Input — ax ≡ b (mod n)
Try 4x ≡ 8 (mod 12) → gcd(4,12)=4 divides 8, so four solutions: 2, 5, 8, 11.
Output

Enter a, b, n — the solvability test, the gcd, the reduced class, and the full solution set will appear here.
