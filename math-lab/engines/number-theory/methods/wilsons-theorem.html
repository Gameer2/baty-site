Wilson's Theorem

A primality test written entirely in factorials: (n−1)! ≡ −1 (mod n) if and only if n is prime. Beautiful, exact, and a *terrible* way to test primality — the factorial explodes long before the work pays off. Here it's a chance to watch an exact equality hold for primes and collapse for composites, computed in BigInt so even (n−1)! for n in the hundreds is exact.

Input
Any integer ≥ 2. The factorial is reduced mod n as it's built, so it stays exact and fast even for large n.
Output

Enter n — (n−1)! reduced mod n, the comparison with −1, and the primality verdict will appear here.
