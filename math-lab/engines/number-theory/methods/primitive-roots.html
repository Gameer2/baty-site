Primitive Roots

A primitive root mod n is an element whose powers hit every unit — order exactly φ(n). They exist only for n ∈ {1, 2, 4, p^k, 2p^k} (p an odd prime). The signature visual is the modular rosette: place g^0, g^1, g^2, … around a circle and connect consecutive powers. A primitive root traces a star polygon that visits every point before closing; a non-primitive base visits only a fraction.

Input
Primitive roots exist for n = 1, 2, 4, p^k, 2p^k. Try 7 (g=3), 11, or 18 (=2·9). 8 has none.
Output

Enter a modulus — the existence verdict, a generator, all primitive roots, and the rosette visual will appear here.
