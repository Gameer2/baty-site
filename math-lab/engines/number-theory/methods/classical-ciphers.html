Cryptography

Classical Ciphers — Affine & Hill

Before RSA, encryption was a permutation of the 26-letter alphabet. The affine cipher E(x) = a·x + b mod 26 needs gcd(a, 26) = 1 for the map to be invertible — exactly the modular-inverse problem from the linear-congruences page. The Hill cipher generalizes this to a matrix acting on letter-blocks; it's invertible only when the determinant is coprime to 26. Both break under frequency analysis, which is why they're a lesson, not a tool.

Input
Affine: a=5 (coprime to 26), b=8. Hill key matrix [[3,0],[0,5]] — diagonal entries entered directly; det = 3·5 = 15, coprime to 26, so it inverts. Try a non-coprime key (e.g. d=2) to see the invertibility failure.
Output

Enter a plaintext and keys — the affine and Hill ciphertexts plus their decryptions will appear here.
