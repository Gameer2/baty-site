Diffie–Hellman Key Exchange

Two parties who've never met agree on a shared secret over a public channel. Pick a prime p and a generator g; each chooses a private exponent, sends the public value g^private mod p, and raises the other's public value to their own private exponent. Both land on g^(ab) mod p — a value an eavesdropper watching every transmitted number cannot compute, because recovering a from g^a is the discrete logarithm problem the previous page showed is hard.

Input
p = 23, g = 5 (a primitive root mod 23). The privates a = 6, b = 15 never travel; only g^a and g^b do. Yet both compute the same shared secret g^(ab) mod 23.
Output
