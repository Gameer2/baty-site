Modular Arithmetic

Work mod n: every result is folded back into the residue class {0, 1, …, n−1}. The addition and multiplication tables are the whole structure on a page — read a row, read a column, see which entries are zero (no inverse) and which wrap around. This is the substrate every later method (congruences, CRT, RSA) sits on.

Input
A positive integer (keep it ≤ 30 so the tables stay readable). Watch the multiplication table: a row is invertible exactly when it never hits 0.
Output

Enter a modulus — the addition and multiplication tables mod n will appear as heatmaps, plus the units (invertible elements).
