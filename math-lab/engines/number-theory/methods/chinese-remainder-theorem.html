Chinese Remainder Theorem

Solve a system x ≡ r₁ (mod m₁), x ≡ r₂ (mod m₂), … simultaneously. When the moduli are pairwise coprime there is a unique solution mod the product — the CRT glues residue classes into one integer. This page also tells you the truth Mathematica hides: when the moduli are *not* coprime, it checks consistency and reports "no solution" with a reason instead of returning a wrong residue.

Input — residues and moduli (comma-separated, same length)
Classic: x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7) → x = 23 (mod 105). Try inconsistent moduli 1,2 with 2,4 to see the honest error.
