Frobenius Number — the Coin Problem

Given two coin denominations a, b with gcd(a, b) = 1, what is the largest amount you cannot make with them? Sylvester answered it: g(a, b) = ab − a − b, and every amount larger than that is reachable. It's the cleanest Diophantine existence result there is — and a direct payoff of the extended Euclidean algorithm from Phase 1, since gcd = 1 is exactly what makes every sufficiently large number representable.

Input — two positive coin values
Coins 3 and 5: you can make 3, 5, 6, 8, 9, 10, … but not 1, 2, 4, 7. The Frobenius number is g(3,5) = 15 − 3 − 5 = 7 — the last unreachable amount.
Output

Enter two coprime coin values — the Frobenius number, the unreachable amounts, and the reachable/unreachable number line will appear here.
