Primality Testing

Is n prime? The obvious test — does a^(n−1) ≡ 1 (mod n) for some base a — is Fermat's test, and it is wrong: the Carmichael numbers (561, 1105, 1729) pass it for every coprime base yet are composite. Miller-Rabin fixes this by watching the squaring chain, and its *witnesses* are the certificate. This page shows both, side by side, with the witness spelled out.

Input
Try 561 (the smallest Carmichael number) with base 2 — Fermat says prime, Miller-Rabin says composite. That gap is the whole lesson.
Output

Enter n and a base — Fermat's test, the Miller-Rabin witnesses, and the Carmichael verdict will appear here.
