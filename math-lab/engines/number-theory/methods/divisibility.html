Divisibility & the Division Algorithm

Every integer statement in this engine builds on one fact: for any integer a and nonzero integer b, there exist unique integers q and r with a = bq + r and 0 ≤ r < |b|. When r = 0, we say b divides a, written b | a.

Input
Any whole numbers — arbitrarily large, exact BigInt arithmetic. b must be nonzero.
Output

Enter a dividend and divisor, then compute — the quotient, remainder, and whether b divides a will appear here.
