Multiple Linear Regression

Fits a plane or hyperplane ŷ = β₀ + β₁x₁ + … + βₚxₚ through (x₁, …, xₚ, y) data by ordinary least squares in matrix form β̂ = (XᵀX)⁻¹Xᵀy — reports each coefficient's standard error, t-statistic, and p-value, plus R² and adjusted R².

Input
One observation per line, comma or space separated. The last column is the response y; all preceding columns are predictors x1…xp — detected automatically from the first row.
Enter at least p + 2 observations, then compute.
Output

Paste observations (one per line, x1, x2, …, xp, y), then compute — the fitted hyperplane, coefficient t-tests, R², and a 3-D scatter with the fitted plane will appear here.
