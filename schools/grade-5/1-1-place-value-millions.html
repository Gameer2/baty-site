Place Value Within Millions

القيمة المنزلية ضمن الملايين

Objective — I determine the place value of a digit in a number within the millions; I read and write numbers within the millions.

the value of the digit you select below
ones

What this teaches: Extends the ones/thousands "period" grouping (each group of 3 digits) to a third period, millions, using a place-value chart with ones/tens/hundreds columns repeated per period. Students identify a marked digit's place value using the chart, and convert numbers between standard form, word form, and expanded form — including real 7–8 digit numbers.
