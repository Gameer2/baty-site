Objective — I evaluate an algebraic expression by substituting a value for its variable.

substitute a value for x

What this teaches: An algebra tile stands for the unknown x, whatever value it takes; substituting a specific value for x turns the expression into a number you can compute, the same way each x-tile expands into that many unit tiles.
