The Coordinate Plane

المستوى الإحداثي

Objective — I locate and name points in the first quadrant of the coordinate plane using ordered pairs.

(x, y) — across, then up

What this teaches: Every point in the first quadrant is named by an ordered pair (x, y): move x units across from the origin, then y units up. Order matters — (3, 5) is a different point from (5, 3).
