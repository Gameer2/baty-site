Mathematica Canvas — v4

Not a general calculator — a teaching space. Each command's visual matches what that command actually is: a list command shows boxes, a shape command shows the shape, a calculus command shows the curve. Text and tokens are bigger throughout.

Lists
Select[{2,7,3,9,4,1,8,5}, #>5&]
the list
what Select keeps
What this teaches: Select[list, test] keeps only the elements where test is true — the boxes that lift up are the ones that passed.
Graphics Primitives
Circle[{0,0}, 1.5]
What this teaches: Circle[{x,y}, r] — a graphics primitive draws the literal object, centered at {x,y} with radius r. No abstraction — what you see is what the command means.
Calculus
D[Sin[x]^2, x]
f'(1) = —
What this teaches: a curve is the natural picture for calculus specifically — the tangent line's slope is f'(1). This visual is used here because the command is inherently about curves, not by default.
