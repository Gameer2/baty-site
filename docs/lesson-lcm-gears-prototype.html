Least Common Multiple

Two gears mesh together. One has fewer teeth than the other, so it spins faster. Both have a marked tooth that starts pointing straight up. Watch how many teeth have to pass before both marks point up again at the same instant — that number is the least common multiple of the two tooth counts.

Demonstrate drag either gear's tooth count
4
6
teeth passed: 0 LCM(4, 6) = 12
What this teaches: a gear with a teeth completes one full turn every a teeth that pass the mesh point; a gear with b teeth completes one turn every b. Both marks return to the top together only when the teeth-passed count is a multiple of both — the smallest such count is the LCM. The ring flashes each time it happens.
